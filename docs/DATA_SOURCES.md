# Data Sources — Baali-Patro (बाली-पात्रो)

This document records where the seed data and live data come from, and how to
replace the bundled estimates with officially verified values.

## 1. Crop calendar data (seeded, static)

The 1,560 calendar rows (5 districts × 6 crops × 52 ISO weeks) shipped in
`backend/data/calendar_master.csv` are **synthesised estimates** built from
publicly documented cropping patterns for the western Nepal Terai. They are
generated by `backend/calendar_app/seed_data.py` using:

- **Stage-span templates per crop** — typical sowing→harvest windows for the
  Terai agro-ecological zone (e.g. paddy: nursery Jestha/June, transplanting
  Asar/July, harvest Kartik–Mangsir/Oct–Nov).
- **District monsoon-gradient offsets** — the monsoon arrives later moving
  west, so stages shift: Kailali **+2 weeks**, Bardiya/Banke **+1 week**,
  Kapilvastu/Rupandehi **+0** (baseline).

### Authoritative sources to verify/replace with

| Source | What it provides | How to use |
|---|---|---|
| **MoALD** — Ministry of Agriculture and Livestock Development (moald.gov.np) | Krishi Diary (कृषि डायरी), annual *Statistical Information on Nepalese Agriculture* | Official sowing/harvest windows per crop and development region |
| **NARC** — Nepal Agricultural Research Council (narc.gov.np) | Variety release notes, regional cropping calendars, agronomy bulletins | Stage durations per released variety (e.g. Radha-4 paddy, Vijay wheat) |
| **DHM** — Department of Hydrology and Meteorology (dhm.gov.np) | Historical rainfall/temperature normals per station | Climate normals to sanity-check stage placement |
| **District Agriculture Knowledge Centres** (Kailali, Bardiya, Banke, Kapilvastu, Rupandehi) | Local cropping calendars, extension advisories | The final word on district-specific timing |
| **FAO/GIEWS Nepal country brief** | National-level crop calendar cross-check | Independent validation |

### Replacing the seed data

1. Prepare a CSV with the same header as `backend/data/calendar_master.csv`:
   `district_code,crop_code,iso_week,stage,activity_en,activity_ne,risk_note_en,risk_note_ne`
2. Drop it in place and run `python manage.py seed_calendar --csv data/calendar_master.csv`
   (the command is idempotent — it upserts by `(district, crop, iso_week)`).

## 2. Weather data (live)

- **Provider**: [Open-Meteo](https://open-meteo.com/) — free, no API key,
  CC-BY-4.0 attribution required (shown in the app footer).
- **Endpoint**: `https://api.open-meteo.com/v1/forecast` with
  `daily=temperature_2m_max,temperature_2m_min,precipitation_sum` for 7 days.
- **Coordinates used** (district headquarters):

| District | HQ | Lat | Lon |
|---|---|---|---|
| Kailali | Dhangadhi | 28.6960 | 80.5898 |
| Bardiya | Gulariya | 28.2620 | 81.3320 |
| Banke | Nepalgunj | 28.0500 | 81.6167 |
| Kapilvastu | Taulihawa | 27.5459 | 83.0507 |
| Rupandehi | Butwal | 27.7006 | 83.4484 |

- **Refresh**: `python manage.py generate_advisories` (run via cron/scheduler,
  e.g. daily at 06:00 NPT), or POST `/api/v1/advisory/regenerate/` with the
  `X-Regen-Token` header.

## 3. Advisory rules (derived)

Rule thresholds live in `backend/advisory/open_meteo.py`:

- Heavy rain: weekly precipitation **≥ 60 mm** → drainage / delay-spray advice
- Moderate rain: **≥ 20 mm** → plan field operations around rain
- Heat stress: max temp **≥ 36 °C** → irrigation / mulching advice
- Cold stress: min temp **≤ 8 °C** → frost protection advice

These are conservative, literature-informed defaults for Terai field crops —
tune them against NARC/DHM guidance before production use.

## 4. Disclaimer

The bundled calendar is an educational approximation. **Always cross-check
with the local Agriculture Knowledge Centre before making field decisions.**
This disclaimer is surfaced in the app footer in both languages.
